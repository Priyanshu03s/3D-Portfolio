## 🌟 Highlights & Key Features

- 🌀 **80-Frame 3D Turntable Canvas Animation**: Smooth scroll-linked image sequence rendering with preloading cache and zero jank.
- 🎯 **Cyber HUD Custom Cursor**: Dual-ring trailing cursor with tactical targeting reticles and interactive hover scaling.
- 💎 **Glassmorphism & Cyberpunk UI**: Sleek dark aesthetic powered by bespoke Tailwind utility tokens and HSL glow filters.
- ⚡ **Lightning Fast Performance**: Zero external heavy 3D engine overhead — sub-second First Contentful Paint (FCP) powered by Vite.
- 🛡️ **Enterprise Project Breakdowns**: In-depth architecture breakdowns of on-premise RAG LLMs, Spring Boot & Angular enterprise systems, and distributed platforms.
- 📱 **Fully Responsive**: Flawless experience across Ultra-wide monitors, Laptops, Tablets, and Mobile devices.
- 🚀 **One-Click Deploy Ready**: Preconfigured with `vercel.json` and Netlify `_redirects` for seamless SPA routing.

## 💻 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18.0 or higher recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### 1. Clone the repository
```bash
git clone https://github.com/Priyanshu03s/3D-Portfolio.git
cd 3D-Portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:5173` to view the 3D portfolio.

### 4. Build for Production
```bash
npm run build
```
The optimized production bundle will be generated in the `dist/` directory.

---

## 🌐 Deployment

### Deploy to Vercel (Recommended)
1. Push your code to GitHub.
2. Go to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import your `3D-Portfolio` repository.
4. Keep the default build command (`npm run build`) and output directory (`dist`).
5. Click **"Deploy"**!
